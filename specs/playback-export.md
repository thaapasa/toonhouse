# Playback and export

- [x] User can watch a cartoon in the browser.
- [ ] The app runs at https://piirretyt.pomeranssi.fi. See
      [Deployment](deployment.md).
- [x] User can watch the cartoon from the start, in full screen.
- [x] A tap on a cartoon in the lists of the app plays it. The owner has a
      separate button to edit it.
- [x] User can pause the cartoon, and move to any point of it with the scrubber.
- [ ] User can save the cartoon as a video file with its sounds, or as images.
- [ ] The video looks sharp at any resolution, and looks the same as in the app.
- [ ] Export runs in the export client on the user's own computer. The client
      downloads the cartoon from the server and writes the files to the local
      disk. The server does no rendering.
