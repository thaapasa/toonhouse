# Sharing

Each cartoon has an owner, the user who made it. The owner decides who can watch
the cartoon in the [player](playback-export.md). Only the owner can edit it. See
[Users and login](users.md) for users and groups.

## Visibility

The visibility of a cartoon tells who can watch it. It is one of these:

1. **Public**: anyone can watch it, also without logging in.
2. **Logged-in users**: every logged-in user can watch it.
3. **Group**: the members of one group can watch it. The owner picks the group
   from the groups they belong to.
4. **Private**: only the owner can watch it.

- [x] The owner can set the visibility of a cartoon to any of the four, on the
      home page and in the editor.
- [x] A new cartoon is private.
- [x] The owner can always watch and edit their own cartoon, whatever its
      visibility.
- [x] A user sees a cartoon in the lists of the app only if they can watch it.
- [x] If a user opens a cartoon that they can't watch, the app tells them that
      there is no such cartoon, so that they don't learn that it exists.

## Editing

- [x] Only the owner can edit a cartoon, its scenes and its cast, change its
      visibility or delete it.

## Open questions

  members of a group?
- If the owner leaves a group, should the cartoons that they shared with the
  group stay visible to its members?
- Should a user be able to copy a cartoon that they can watch, to edit their own
  version of it?
