# Library

The library is made of asset packs. Each pack has its own art style, so that the
characters, props and backgrounds in it look like they belong together. The
first pack, Sunny, has the characters, props and backgrounds made so far. Later
packs can have very different styles.

- [ ] The library shows the characters, props and backgrounds grouped by asset
      pack.
- [ ] User can use characters, props and backgrounds from different asset packs
      in the same scene.
- [ ] Each asset pack has a name in Finnish and in English.
- [x] Each asset pack has a style prompt, which the developer uses to generate
      new assets in the style of the pack. See
      [assets/CLAUDE.md](../assets/CLAUDE.md).
- [ ] Each asset pack has a default font for speech bubbles. The fonts are free
      fonts that the app serves itself.
