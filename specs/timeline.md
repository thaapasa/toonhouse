# Timeline

The timeline works like in Cartooners. The user moves to a point in time and
starts an action for a character there. The action goes on until the user starts
another action for that character.

- [ ] User can move to any point on the timeline, by scrolling it or by stepping
      one frame at a time.
- [ ] User can start an action for a character at the current point, such as
      walking somewhere, waving or jumping.
- [ ] An action goes on until the next action of the same character.
- [ ] User can make a character walk to a point or along a path. The feet don't
      slide on the ground.
- [ ] User can add a speech bubble to a character for a time.
- [ ] User can add a sound at the current point.
- [ ] User can play the cartoon from the current point and stop it to add the
      next action.
- [ ] User can change or remove an action.
