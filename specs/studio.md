# Character studio

A development tool for making the built-in characters, props and clips. It runs
only on the developer's computer, and it saves its changes to the asset files in
the repo. See [Characters](characters.md).

- [ ] Developer can pick a character or a prop and play any of its clips.
- [ ] Developer can play a clip on every character that it works on.
- [ ] Developer can move the pivot points of a character and save the rig.
- [ ] Developer can edit the keyframes of a clip and save it.
- [ ] The studio isn't part of the production build.
